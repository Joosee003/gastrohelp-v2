WhatsApp no debe convertirse en otro calendario

El canal es cómodo para el cliente, pero la reserva debe terminar registrada en el sistema del restaurante. Si queda solo dentro de una conversación, es fácil perder cambios, duplicar mesas o dejar una petición sin confirmar.

Proceso

Cómo funciona una reserva por WhatsApp

01

El cliente inicia la conversación

Puede llegar desde Google, la web, Instagram, un QR o el número del restaurante.

02

Se recogen los campos obligatorios

El chatbot del restaurante o el equipo solicita los datos que faltan.

03

Se consulta disponibilidad

El sistema revisa las reglas del calendario de reservas.

04

La reserva queda registrada

Se guarda fecha, hora, personas, estado, origen y cliente asociado.

05

El cliente recibe confirmación

El mensaje resume la información y explica cómo pedir un cambio o cancelar.

Disponibilidad

Aforo, turnos y mesas antes de confirmar

La respuesta no debería depender solo del número total de reservas. El restaurante puede definir límites por personas, franja, zona, tamaño de grupo o mesas disponibles.

Cambios

Confirmaciones, cancelaciones y reprogramaciones

El mismo canal puede servir para mantener el estado actualizado. Cuando el cliente pide un cambio, el sistema debe comprobar de nuevo la disponibilidad y conservar el historial de la reserva.

  • Confirmación con fecha, hora, personas y nombre.
  • Recordatorio antes del servicio cuando esté configurado.
  • Enlace o instrucción clara para cancelar.
  • Revisión de cambios cercanos a la hora de la reserva.
  • Registro de cancelada, completada o ausente.
  • Aviso al equipo cuando el caso necesita atención.
Clientes

WhatsApp conectado con el CRM

El teléfono permite buscar una ficha dentro del CRM para restaurantes. Si el cliente ya existe, la nueva reserva se añade a su historial; si no existe, se crea un perfil con el origen y los datos permitidos.

La normalización del teléfono es importante para evitar que el mismo cliente aparezca varias veces por usar espacios, prefijo internacional o formatos diferentes.

Resultado esperado

La conversación termina con una reserva visible, un estado claro y una ficha de cliente correcta.

Automatización

Qué debe seguir bajo control humano

Las peticiones especiales, grupos grandes, incidencias, cambios fuera de política y dudas no cubiertas deben pasar al equipo. La automatización para restaurantes debe distinguir los casos claros de los que necesitan criterio.

Preguntas frecuentes

Dudas sobre reservas por WhatsApp

¿Puedo seguir atendiendo conversaciones manualmente?+

Sí. El sistema puede recoger o preparar datos y dejar al equipo la confirmación final, según la operativa elegida.

¿Se puede usar el número actual del restaurante?+

Depende del proveedor, la configuración de WhatsApp y el tipo de integración. Se revisa antes de implantar el flujo.

¿Las reservas aparecen en el panel?+

Sí, cuando WhatsApp está conectado con el sistema de reservas y la base de clientes.
